# Directions

## Direction A — Calm Live Operations

Selected.

- Keep the existing Dark Ops Console and compact canvas.
- Make local authoring, collaboration, durable save, validation, publication, execution, and evidence separate visible states.
- Use one right-side Workflow Dock rather than more floating surfaces.
- Let demand provenance and grounded evidence appear where operators make decisions.
- Use bounded semantic motion only for direct manipulation, spatial navigation, connection creation, and acknowledgement.

Fit: highest. It preserves current product identity and repairs the exact trust and latency problems reported by operators.

Risk: dense status language can become noisy. Mitigation: progressive disclosure and one primary status per region.

## Direction B — Evidence-First Review Desk

- Give Evidence and Lineage equal visual weight to the canvas.
- Use a persistent split view for source URLs, grounded claims, and acceptance gates.
- Optimize for reviewers rather than authors.

Fit: strong for audit sessions, weak for everyday authoring. Rejected as the default direction because it reduces canvas space and makes simple edits feel like review work. Retain as the project Evidence workspace, not the editor shell.

## Direction C — Ambient Collaborative Canvas

- Emphasize presence, live cursors, animated edge flow, and multiplayer identity.
- Treat collaboration as the primary visual theme.

Fit: low. Rejected because it overstates collaboration, adds motion noise, and risks turning operational truth into decorative activity. Presence remains a compact status layer inside Direction A.

## Decision

Adopt Direction A. Use Direction B only when the operator explicitly enters Evidence or Trace. Reject Direction C's ambient motion and collaboration-first visual identity.
